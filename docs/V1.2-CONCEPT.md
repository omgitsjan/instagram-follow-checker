# Instagram Follow Checker – v1.2 Concept

**Branch:** `feature/v1.2-insights-analytics`  
**Release:** `1.2.0`  
**Status:** Relationships + charts + bots; Posts/Admire coming soon.  
**Deferred:** Impersonator (other-account analysis) — unreliable with web session limits.

---

## Product vision

Keep the **single product purpose** (understand Instagram relationships in the browser), organized into **top-level sections**:

| Section | Purpose |
|---------|---------|
| **Relationships** | Following/followers, mutual, not back, not following |
| **Analytics** | Doughnut charts + rates from list buckets |
| **Bots** | Heuristic “likely low-quality / bot-like” scores on **your followers** |
| **Posts / Admire** | Coming soon (post fans, story viewers — blocked or fragile on web) |

English UI default; German remains in Settings.

---

## Architecture

```
┌─────────────────────────────────────────┐
│ Header · account · settings (gear ↔ ×)  │
├─────────────────────────────────────────┤
│ [ Relationships ] [ Analytics ] [ Bots ] [ Posts ] [ Admire ]
├─────────────────────────────────────────┤
│ Section-specific lists / charts         │
└─────────────────────────────────────────┘
```

- **Content script** owns Instagram session fetches.
- **Popup** owns navigation, i18n, rendering, local cache.
- **analytics.js** pure functions: bot score, chart buckets, summarize (no Chrome APIs).

### Data sources (session only, no official Graph API)

| Source | Endpoint pattern | Used for |
|--------|------------------|----------|
| Following / followers pages | `/api/v1/friendships/{id}/following|followers/` | Relationships + analytics base |
| User fields on list items | private, verified, anonymous pic | Privacy/verified charts + bot signals |
| Optional light enrich | `/api/v1/users/...` | Sample of followers for bot counts (capped) |

---

## Feature details

### 1. Relationships

Top tiles + three relationship tabs + follow/unfollow + search + JSON export.

### 2. Analytics

Derived **only** from already loaded lists:

- Metrics: mutual rate, not-back rate, one-way followers, bot-flagged count  
- Doughnuts: following split, followers split, network mix  
- Doughnuts: audience balance, followers privacy, following verified, bot-risk tiers  

No “most followers” rankings (public counts rarely on list payloads). No separate Analytics export.

### 3. Bots (heuristic – not ground truth)

Score 0–100; UI shows score ≥ 25 only. Unfollow / remove-follower actions when available.

### 4. Posts / Admire

Coming soon placeholders (session endpoints unstable or blocked).

Still **website content** only in the browser. Bot labels must never be marketed as “official bot detection”.
